Spring Boot 3 Enterprise Web Application

FitZone Gym Management System

Full-stack Enterprise Java Web Application built with Java 21 LTS, Spring Boot 3, Spring MVC, Thymeleaf, MySQL (`gymdb`), Firebase Auth & Storage, iText PDF, and Apache POI.

GitHub Repository Installation Guide

System Overview

Java 21 LTS

Powered by Java 21 & Spring Boot 3.2.4 framework

MySQL (`gymdb`)

Relational system of record preserving all PHP & desktop data

Firebase Cloud

Firebase Authentication & Cloud Storage for media assets

iText & POI Reports

Branded PDF receipts, QR member cards, and Excel exports

Enterprise Architecture

Browser (Client) ──► Spring Boot 3 Web Application (Port 8080)
                       ├── Spring Security (BCrypt & Firebase Auth)
                       ├── Spring MVC & Thymeleaf Templates
                       └── Service Layer
                             ├── MySQL Database (gymdb) [System of Record]
                             ├── Firebase Storage (Profile Photos & Document PDFs)
                             ├── iText PDF Engine (Receipts & Member ID Cards)
                             ├── Apache POI Engine (Excel Reports .xlsx)
                             └── ZXing Generator (QR Code Matrices)

Core Modules

Member Management

Full CRUD, real-time search, photo handling, duplicate validation, and printable PDF Member QR Cards.

Trainer Directory

Fitness instructor management, specialties, joining dates, monthly salary payouts, and status tracking.

Payments & Invoicing

Cash, Card, and UPI payments with ZXing QR code modals and branded iText PDF invoice generation.

Attendance & Check-In

Manual check-in, QR/Barcode scanner event listener, and daily attendance log reporting.

Quick Start & Installation

1. Import MySQL Database
mysql -u root -p gymdb < sql/gymdb_upgrade.sql
2. Build & Package
mvn clean package
3. Launch Web Server
java -jar target/FitZoneGymManagementWeb-1.0-SNAPSHOT.jar

Open browser at http://localhost:8080 (Credentials: admin / admin123)
