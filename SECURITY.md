# Security Policy

## Security Features

- **Spring Security**: Form login, session management, CSRF protection, and role-based authorization.
- **Firebase Auth Integration**: Secure identity verification.
- **Password Security**: BCrypt password hashing with transparent legacy MD5 migration support.
- **SQL Injection Prevention**: Prepared Statements used across all DAO implementations.
- **Zero Exposed Secrets**: Database credentials loaded from `application.properties`.
